# CAPA 有效性分析规则

不能只统计 CAPA 数量，要看 CAPA 是否真正防止复发。

## 基础统计维度
- CAPA 发起数量
- 按根因分类 / 按部门分类
- 按时关闭率、逾期率
- 临时纠正 vs 系统性预防措施的比例
- 同一根因重复 CAPA 次数
- CAPA 完成后 3/6/12 个月内是否出现同类事件

## 疑似无效判定规则（输出仅作回顾提示，不作最终有效性判定）
1. CAPA 关闭后 6 个月内，同一产品+同一工艺步骤+同一根因再次发生 → 标记"疑似无效"
2. 同一根因在不同部门重复发生 → 标记"系统性问题"（指向培训/SOP/维护/变更评估等系统缺陷）
3. 高严重性但低频次事件：单独列出，不因频次低而省略（高风险低频事件清单）

## 与重复事件分析（Q6）的衔接
重复事件三分类（完全/相似/系统性）是 CAPA 有效性的输入：同类事件在 CAPA 关闭后再次出现，即为 CAPA 未见效的证据。判定输出到 13_Repeat_Events 和 14/15_CAPA sheet，并喂给 17_Recommended_Focus_Areas。

## 边界
CAPA 有效性最终判定由 QA 做出；分析脚本只能标记"疑似"，结论段必须写"需 QA 确认"。
