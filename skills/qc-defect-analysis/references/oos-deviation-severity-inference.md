# OOX/偏差/验证偏差 严重性推断规则

## 概述

当数据源无严重性分级字段时，从描述文本中通过关键词匹配推断。适用于OOX、偏差、验证偏差三类数据源。

## 评分规则

对每条记录，将 `描述 + 根因 + 检项` 拼接为全文，与关键词列表匹配计分：

| 分数 | 严重性 | 判定条件 |
|------|--------|---------|
| ≥3 | 🔴 高 | 多项高危关键词命中 |
| 1-2 | 🟡 中 | 单项高危关键词命中 |
| 0 | 🟢 低 | 无高危关键词命中 |

## 高危关键词列表

| 关键词 | 含义 | 示例场景 |
|--------|------|---------|
| 过期 | 试剂/滴定液过期使用 | 滴定液超出标定有效期 |
| 数据 | 数据完整性相关 | 数据修改、审计追踪 |
| 电子 | 电子数据系统 | 电子记录、电子签名 |
| 审核 | 审核追溯问题 | 审核遗漏、追溯链断裂 |
| 追溯 | 追溯性问题 | 无法追溯操作人/时间 |
| 警报 | 警报系统异常 | 软件警报缺失/覆盖 |
| 缺失 | 数据/信息缺失 | 警报信息缺失、原因未填 |
| 覆盖 | 数据覆盖 | 循环覆盖、数据存档异常 |
| 混淆 | 样品混淆 | 误将A样品当作B样品 |
| 用错 | 方法/参数用错 | 调用错误方法、用错参数 |
| 泄漏 | 物理泄漏 | 大漏阳性对照 |
| 阳性对照 | 对照样品异常 | 阳性对照结果不符合预期 |
| 100% | 100%不符合 | 阳性对照应100%不通过但部分通过 |
| 大漏 | 大泄漏 | 密封性测试中大泄漏 |
| 重复 | 重复发生 | CAPA后同类事件重复 |
| 未关闭 | 事件未关闭 | 调查逾期未完成 |
| 不一致 | 结果不一致 | 肽图/图谱与参比品不一致 |

## 特殊场景

### 验证偏差特殊关键词
- "决定系数" + "<" + 接受标准 → 中
- "RSD" + ">" + 接受标准 → 中
- "阴性样品" + "Fail" → 中
- "阳性对照" + "Pass"（应Fail时）→ 高

### OOE特殊处理
- OOE（异常观察）通常严重性低于OOS，但若涉及TOC等关键指标，仍可能为中
- OOE的"是否实验室原因"列可能存在，需纳入评估

## 实施示例

```python
HIGH_RISK_KEYWORDS = ['过期','数据','电子','审核','追溯','警报','缺失','覆盖',
    '混淆','用错','泄漏','阳性对照','100%','大漏','重复','未关闭','不一致']

def infer_severity(desc, rc, item):
    text = str(desc) + ' ' + str(rc) + ' ' + str(item)
    score = sum(1 for kw in HIGH_RISK_KEYWORDS if kw.lower() in text.lower())
    if score >= 3: return '高'
    elif score >= 1: return '中'
    return '低'
```
